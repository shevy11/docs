---
title: "Install an eSIM Manually on iPhone or Android"
sidebarTitle: "Install manually"
description: "How to install a SimSIM eSIM by entering the SM-DP+ address and activation code manually on iPhone or Android — when the camera on the target device isn't working."
---

Use this method if the camera on the target device isn't working and you can't scan the QR code. You'll need two values from the SimSIM app: the **SM-DP+ address** and the **Activation code**. Find them under **My eSIMs** → your plan → the three-dot menu → **Show QR / Manual install**.

<Note>
An eSIM can only be installed on one device and cannot be shared or transferred to another phone.
</Note>

<AccordionGroup>
  <Accordion title="Installing for someone else" defaultOpen>
    Open the SimSIM app, navigate to the codes, and tap the share button to send them to the other person so they can type them into their device.

    **On iPhone**

    <Steps>
      <Step title="Open eSIM settings">
        On the target phone, go to **Settings → Cellular** (or **Mobile Data**). Tap **Add eSIM**.
      </Step>
      <Step title="Choose manual entry">
        Tap **Use QR Code**. On the next screen, select **Enter Details Manually**.
      </Step>
      <Step title="Enter the SM-DP+ address">
        Type or paste the SM-DP+ address exactly as shown in the app. Tap **Next**.
      </Step>
      <Step title="Enter the activation code">
        Type or paste the activation code. Leave the confirmation code field empty. Tap **Next** to start the download.
      </Step>
      <Step title="Confirm adding the eSIM">
        Tap **Continue**, then **Add Cellular Plan**. Installation takes a few minutes.
      </Step>
    </Steps>

    For detailed setup instructions, see the [iPhone installation guide](/en/install-esim-iphone).

    **On Android**

    <Steps>
      <Step title="Open SIM manager">
        On the target phone, go to **Settings → Connections → SIM manager**. Tap **Add eSIM** or the **+** button.
      </Step>
      <Step title="Choose manual entry">
        Select **Enter activation code** or **Add using activation code**, depending on the device.
      </Step>
      <Step title="Enter the SM-DP+ address and activation code">
        Enter the SM-DP+ address in the first field and the activation code in the second. Tap **Connect** or **Confirm**.
      </Step>
      <Step title="Confirm the installation">
        Tap **Confirm** when the plan details appear. Installation takes a few minutes — don't close the screen.
      </Step>
    </Steps>

    For detailed setup instructions, see the [Android installation guide](/en/install-esim-android).
  </Accordion>
