<div dir="rtl">
  פתח eSIM מתוך **ה-eSIM שלי** כדי לראות את המצב, יתרת הנתונים, התוקף, הרשת, פרטי החבילה והפעולות הזמינות.

  ## מצבי eSIM

  | מצב               | משמעות                                                    |
  | ----------------- | --------------------------------------------------------- |
  | **מוכן להתקנה**   | הפרופיל זמין אך עדיין לא הותקן במכשיר.                    |
  | **מחובר**         | הפרופיל מותקן ופעיל.                                      |
  | **ה-eSIM כבוי**   | הפרופיל מותקן אך כבוי בהגדרות המכשיר.                     |
  | **הנתונים נוצלו** | לא נותרו נתונים בחבילה. זמינות טעינה נוספת תלויה בתוכנית. |
  | **פג תוקף**       | תוקף החבילה הסתיים. קנה eSIM חדש כדי להמשיך.              |
  | **מושעה**         | ספק הרשת השהה את הפרופיל. פנה לתמיכה.                     |
  | **לא זמין**       | הפרופיל בוטל או בוטל על ידי הספק ולא ניתן להשתמש בו.      |

  כאשר הפעולות זמינות, אפשר לשנות שם ל-eSIM, להעתיק ICCID, לפתוח את פרטי החבילה, לפנות לתמיכה ולהעביר eSIM סופני לארכיון.

  <Warning>
    אל תמחק eSIM פעיל או מושעה מהמכשיר. ייתכן שלא ניתן יהיה להתקין מחדש פרופיל שנמחק.
  </Warning>
</div>
